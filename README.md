# sua-updates

메이플 뉴비 도우미의 **설치·업데이트 파일 전용 저장소**입니다. 개발 소스와 사용자 데이터는 이 저장소에 게시하지 않습니다.

## 설치

1. [최신 Windows 설치 파일 다운로드](https://github.com/suachoi-code/sua-updates/releases/latest/download/MapleNewbieHelperWpf-win-Setup.exe)
2. 내려받은 `MapleNewbieHelperWpf-win-Setup.exe`를 실행합니다.
3. 설치된 앱의 바로가기로 실행합니다. .NET 런타임을 별도로 설치할 필요는 없습니다.

[버전별 배포 파일과 릴리스 보기](https://github.com/suachoi-code/sua-updates/releases)

최초 한 번은 설치본으로 설치해야 합니다. 이전 검수용 ZIP의 `Start-Demo.cmd`는 자동 업데이트 설치본의 바로가기가 아닙니다.

## 이후 업데이트

앱이 시작할 때와 실행 중 6시간마다 새 안정 버전을 확인하고 다운로드합니다. 상단에 **업데이트 후 재시작**이 표시되면 눌러 적용합니다. 타이머가 실행 중이면 일시정지한 뒤 적용할 수 있습니다. 파일을 직접 복사할 필요는 없습니다.

캐릭터·설정·사냥 기록은 기존 사용자 데이터 폴더를 사용합니다. `--data`로 지정한 사용자 경로도 재시작 시 유지합니다. 다운로드/통신/검증에 실패하면 현재 앱을 유지하며 재시도할 수 있습니다.

`--demo`와 `--review`는 예시 화면을 위한 오프라인 모드로, 자동 업데이트를 확인하지 않습니다. 설치본은 일반 실행 모드이므로 실제 데이터가 없으면 빈 상태가 표시됩니다.

## 개발 상태

현재는 메인 대시보드 개발 단계입니다. 공식 이미지 확보와 Windows 11 디자인 검수는 진행 중이며, 다른 화면의 기능 완성을 의미하지 않습니다. 설치본 게시/핵심 테스트와 별도로 실제 PC에서 최초 설치 및 버전 간 업그레이드 확인이 필요합니다.
